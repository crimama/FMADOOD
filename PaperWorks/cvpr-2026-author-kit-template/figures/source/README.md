# Review figure sources

Run from the paper directory using the project's existing Python environment:

    MPLCONFIGDIR=/tmp/scopead-mpl ../../.venv/bin/python figures/source/draw_overview.py
    MPLCONFIGDIR=/tmp/scopead-mpl ../../.venv/bin/python figures/source/draw_review_figures.py
    make all

Outputs are PDF, PNG and SVG files under this paper's figures directory.

All current manuscript figures use actual Times New Roman (regular, bold,
italic and bold italic), including math text. `figure_style.py` shares these
settings and fails if the family is unavailable, rather than silently using a
substitute. Install Times New Roman through the system font manager, or place
its TTF files in `~/.local/share/fonts/times-new-roman/`. Fonts are embedded in
PDF exports; SVG labels remain editable. The membership and transpose symbols
absent from the installed Times New Roman use Times-compatible STIX glyphs.
