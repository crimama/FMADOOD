# Coverage-void instrumentation — locked protocol

Registered before any cell is executed. Decision rules below are fixed; results
may not be reinterpreted against different thresholds afterwards.

## Question

Few-shot support budget (a deployment constraint) and acquisition shift (an
environmental change) are two independent exogenous conditions. Do they act
through a *shared* mediating state — normal query pixels falling outside the
normal variation the support observed (a coverage void) — or through separate
mechanisms that merely both degrade performance?

## Measured void statistics (normal pixels; defect pixels as contrast)

Calibration fixes an a-priori null for the shallow gate. The gate is the support
q99, so a support-like normal query is expected to activate it on 1% of its
pixels. Deviation from that null is the void measurement.

- `V1 normal_gate`       fraction of normal pixels with z5 > support q99. Null 0.01.
- `V2 normal_residual`   mean ReLU(z5 - q99) over normal pixels. Null ~0.
- `V3 normal_deep_q95`   fraction of normal pixels with normalized deep > 1.
- `V4 gate_selectivity`  defect_gate / normal_gate.
- `V5 void_inflation`    V1 / 0.01. Primary summary.

Correction registered 2026-09-22, before matrix collection and after a single
pilot cell (can, 16-shot, gated). An earlier draft of this protocol assigned V3
an a-priori null of 0.05, reasoning that tail scaling divides by the support q95.
That null is wrong. The deep score is the MEAN of two layer scores, and averaging
suppresses joint exceedance, so the per-layer 5% rate does not carry over to the
mean. The pilot measured 0.0050 on `regular`, an order of magnitude below the
stated null, which exposed the error. V3 therefore carries NO absolute null and
is read only as a change relative to the `regular`, 16-shot cell of the same arm.
No decision rule below depends on V3. V1 and V5 keep the 0.01 gate null, which
the same pilot supported: `regular` V5 was 1.16, close to the predicted 1.0.

Pixel-weighted within condition. Masks stratify normal and defect pixels only
after prediction; they never enter fitting, scoring, or threshold selection.

## Fixed comparison

- Dataset MVTec AD 2, `test_public`, all 8 objects, seed 0, frozen DINOv2-L/14.
- Cause A, support budget: shots 1, 2, 4, 8, 16 from strictly nested manifests
  (`VOID_support_N.json`, N-shot is the first N entries of 16-shot). Nesting is
  required so the shot effect is not confounded with manifest draw luck.
- Cause B, acquisition condition: regular, underexposed, overexposed, shift_1,
  shift_2, shift_3. These are strata of the same query population, resolved from
  filenames, so they cost no extra cells.
- Arms: `gated` (ours), `all` (ungated shallow), `off` (deep only). Resolutions,
  banks, bags, CQ postprocessing, evaluator and query order are identical.
- No target adaptation, no threshold transfer, no per-class selection.
- 5 shots x 3 arms x 8 objects = 120 cells. Local GPU, no remote runners.

## Pre-registered decision rules

Judged against the established 0.865pp AUPRO measurement noise floor. A
difference below the floor is reported as direction only, never as an effect.

- H1 support budget moves the void: V5 increases monotonically as shots fall
  from 16 to 1, with V5(1-shot)/V5(16-shot) >= 2.0, at fixed `regular`.
  Fail -> drop the claim that few-shot acts through coverage void.
- H2 acquisition change moves the void: at fixed 16-shot, V5(shift_1) > V5(regular),
  and V5(underexposed), V5(overexposed) < V5(shift_1).
  Fail -> drop the claim that shift acts through coverage void.
- H3 predicted failure boundary: gate selectivity V4 falls as V5 rises, and the
  arm ranking degrades where V5 is largest.
  Fail -> the void is not what limits the method; report as such.
- H4 SHARED MEDIATOR, decisive: regress AUPRO loss on log V5 separately for the
  shot family (regular, varying shots) and the shift family (16-shot, varying
  condition). Over the overlapping V5 range the two fitted relations must differ
  by less than 0.865pp in predicted AUPRO.
  Fail -> the "two causes, one mediator" argument is discarded and Outline
  section 1 reverts to the weakened formulation.
- H5 the intervention tracks the void: the gating gain (gated minus all) is
  non-decreasing in V5.
  Fail -> gating is reported as an empirical gain, not as a void remedy.

## Validity and stopping

Fail collection on missing cells, non-finite or shape-invalid predictions,
support identity or content drift across conditions, or config drift. Report
every completed arm, shot, object and condition; selective reporting of
favourable classes or conditions is prohibited. Stop when the declared 120-cell
matrix is complete. No additional shot, seed, arm or dataset sweep is authorized
under this protocol. Seed 0 only; void statistics are not seed-generalized here.
