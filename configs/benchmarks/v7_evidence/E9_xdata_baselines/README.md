# E9: Few-Shot Baselines

Few-shot evaluation of baseline methods on MVTec AD and ViSA.

## Methods

- regad: Region-based Anomaly Detection
- rd4ad: Reverse Distillation 4 Anomaly Detection
- patchcore: PatchCore with DINOv2
- fastrecon: FastRecon
- rn_fmlk: ResNet FMLK
- superad: SuperAD (DINOv2 and DINOv3 variants)

## Datasets

- MVTec AD 2
- ViSA

## Configurations

Per-method, per-dataset, per-shot (1, 2, 4, 8, 16) configurations.
