# RSG4 MVTec AD 2 few-shot scaling — controlled development protocol

Registered 2026-09-26 before executing an RSG4-labeled MVTec AD 2 cell.

## Question and hypothesis

Does the canonical RSG4 implementation execute validly across 1/2/4/8/16
normal supports on MVTec AD 2? Because the noise guard previously fired zero
times on this clean acquisition-shift population, the prospective hypothesis is
that each RSG4 cell exactly reproduces its matched RSG3 cell. This is an
equivalence/reproducibility test, not an expected performance improvement.

## Controlled comparison

- Candidate: RSG4 = RSG3 plus Immerkaer query-noise ratio guard, k=9, with a
  fired-query action restricted to resolutions [448, 672].
- Comparator: stored RSG3 gated runs with the same shot-specific support
  manifests and evaluator contract.
- Dataset/split: MVTec AD 2 full8, `test_public_seen_development`; query masks
  and labels are evaluator-only and are never available to fitting/prediction.
- Backbone/features: frozen DINOv2 ViT-L/14, layers [5, 11, 23].
- Support: seed 0, fixed nested `VOID_support_{1,2,4,8,16}.json` manifests.
- Primary metric: macro AUPRO@0.05, with pAUROC@0.05 secondary and F1-oracle
  diagnostic. Direction: exact equality to matched RSG3 when firing count is 0.
- Budget: 5 shots × 8 classes = 40 cells. Four assigned dsba3 GPUs, at most two
  workers per GPU. Quantitative metrics/config/manifests/logs retained; anomaly
  maps and fitted weights disabled.
- Stop condition: finish all 40 valid cells. Do not stop for low performance.
  Stop a lane only for invalid provenance, non-finite/incomplete output, or a
  repeated runtime failure that cannot be safely resumed.

Seed 1–2 replication is a later phase and is intentionally deferred until the
seed-0 scaling matrix is complete, per user priority.

## Endpoint replication phase (registered after seed-0 scaling completed)

- Seed 2 runs the fixed-support 2-shot and 16-shot endpoints with the existing
  E1 seed-2 manifests; seed 1 used the corresponding E1 seed-1 manifests.
- This phase estimates support-set/seed sensitivity at the low- and high-shot
  endpoints; it does not retroactively change the seed-0 scaling hypothesis.
- The same full-eight scope, split, backbone, method, metrics, output policy,
  and stop conditions remain fixed. dsba3 runs seed-2 16-shot while the local
  RTX 4090 runs seed-2 2-shot.
