# Gaussian-noise failure attribution — locked protocol

Registered before any cell is executed.

## Question

Under ICCV-2023 severity-3 Gaussian noise on MVTec AD, RSG3 loses 20.69pp
AUPRO (85.36 -> 64.67), while same-backbone kNN comparators lose far less
(PatchCore -9.94, SuperAD -13.39; results/comparisons/corruption_compare_20260922).
The failure is therefore specific to the RSG3 pipeline. Which component carries it?

## Candidates and arms

All arms share frozen DINOv2-L/14, 16-shot seed0 rng support, 4 bags, kNN k=1,
tail q95 scaling, the evaluator, and query order. Each arm changes one factor.

- `NA_gated`  control: layers [5,11,23], resolutions [448,672,896,1120], q99 gate, CQ.
              Must reproduce the stored RSG3 cells (clean 85.3614, noise 64.6741).
- `NA_off`    shallow branch removed (deep-only).            Tests layer 5.
- `NA_lowres` resolutions [448,672] only.                    Tests the high-res pyramid.
- `NA_nocq`   prediction_postprocess none.                   Tests CQ filling.

Conditions: clean (`MVTecAD`) and gaussian_noise sev3 (the stored
`MVTecAD_corrupted/gaussian_noise` root; noise generation is unseeded, so the
stored root is the only valid one). Local and dsba3 clean roots are byte-identical
(6612 files, sha256 ad34969bf52fdd0f). 4 arms x 2 conditions x 15 classes = 120 cells.

## Pre-registered decision rules

Let drop(arm) = AUPRO_noise - AUPRO_clean, 15-class macro, and
relief(arm) = drop(arm) - drop(NA_gated). The gap to PatchCore is 10.75pp; a
component "carries" the failure if removing it relieves at least 3.0pp (~30%).

- C0 control: NA_gated reproduces both stored macros within 0.05pp. Fail -> stop.
- A1 shallow:    relief(NA_off)    >= 3.0pp -> layer 5 carries the failure.
- A2 resolution: relief(NA_lowres) >= 3.0pp -> the 896/1120 branches carry it.
- A3 CQ:         relief(NA_nocq)   >= 3.0pp -> CQ filling carries it.
- Clean cost of each arm (AUPRO_clean(arm) - 85.3614) is reported alongside, since
  a remedy that removes a component everywhere would pay that cost on clean data.

Several of A1-A3 may pass; all are reported. None passing -> the failure is not
localized to a single component, and the remedy design must act on the input.

## Remedy constraint registered in advance

A label-free per-query noise estimate (Immerkaer 1996, native grayscale) will gate
any remedy, with threshold k = 9 x the class support median. On an unlabeled
sample (1182 non-noise images incl. clean, photometric, blur, JPEG and all six
MVTec AD 2 acquisition strata; 1440 noise images, 4 noise types x severities 1-5)
the non-noise maximum ratio is 6.08 and the noise minimum 13.46; k = 9 is their
geometric midpoint. k was fixed from image statistics only, without any model
output or label. A remedy that never fires leaves predictions byte-identical.

## Scope

Seed 0 development evidence. No target adaptation, no maps or weights saved.
Stop when the declared 120 cells are complete.
