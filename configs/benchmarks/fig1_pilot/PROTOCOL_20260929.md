# Fig. 1 pilot protocol

Registered 2026-09-29 before any `fig1_pilot` result. This is a post-hoc
diagnostic ablation for the Section 1.2 teaser, not a method change or final
evaluation. Split: `mvtec_ad2_test_public_dev_analysis_no_label_selection`;
seed 0; eight MVTec AD 2 classes; DINOv2 ViT-L/14. All arms use the
`configs/methods/VOID_support_{1,2,4,8,16}.json` manifests shared with
`void_instrumentation_20260922`. Labels are used only for evaluation and
diagnostic figure colouring and aggregation, never for fitting, fusion, or
method selection.

| Arm | `shallow_mode` | `score_normalization` | Score rule |
|---|---|---|---|
| off (existing void) | off | tailscale | deep-only, layers 11 and 23 |
| all (existing void) | all | tailscale | Q-alpha deep mean plus full shallow, weights 0.5/0.5/1 |
| gated (existing void) | gated | tailscale | excess over support tau only |
| raw_mean3 (new) | mean3 | none | uncalibrated equal mean of three raw NN distances |
| qa_mean3 (new) | mean3 | tailscale | Q-alpha-calibrated equal mean of three layer scores |

## Stage 1 decision rule

At 16 shots, use all-test macro pAUROC@0.05 and the registered development
noise floor of 0.86 percentage points. Let delta be
`pAUROC(raw_mean3) - pAUROC(off)`.

- Delta <= -0.86: the fixed rule degrades. Run 1/2/4/8-shot `raw_mean3` and
  `qa_mean3`; retain the three-line design for Fig. 1(a).
- Absolute delta < 0.86: stop expansion, report per-layer raw scale using
  normal medians and q95 from `raw_l*` audit, then reconsider Fig. 1(a) with
  the user.
- Delta >= +0.86: report and reconsider the design with the user.

Report the same rule for AUPRO@0.05, but only pAUROC@0.05 decides.

## Fig. 1(c) case selection

For each class, compute `d_c = pAUROC_c(off) - pAUROC_c(fixed-rule arm used
in (a))` at 16 shots. Select the class with the fourth-largest `d_c` as the
primary case and the class with the smallest `d_c` as a counter-case. Within
each class, sort `test_public/bad` filenames and use
`numpy.random.RandomState(0).choice(n, 2, replace=False)` to select two defect
images. Sort `test_public/good` filenames and use the same generator,
continuing its state, to select one normal image. Show all selected images;
do not replace any after viewing.

For each arm, set a class-level score threshold at 5% normal-pixel FPR,
pooled over that class's test pixels. Mark above-threshold normal pixels red
and defect pixels green.

## Fig. 1(b) definition

For each arm and class, convert pixel scores to percentiles within that
class's normal-pixel score distribution. Plot the defect-pixel percentile
distribution pooled over eight classes, weighting each class equally. Draw
the 95th-percentile line and annotate the defect fraction above it.
