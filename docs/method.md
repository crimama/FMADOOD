## 1. 한 문장으로 이해하기

**사전학습된 고정 DINOv2에서 정상 이미지 16장의 다중 스케일 패치 특징을 희소 뱅크로 저장해 두고, 검사 이미지와의 거리를 '오탐 예산' 단위(꼬리 정규화)로 환산한 베이스 지도에 얕은 레이어의 신뢰할 수 있는 결함 신호(잔여 스파이크 게이팅)만을 적응적으로 융합한 뒤, 패치 표현의 공간적 파편화를 극복하고 온전한 물리적 결함 형태를 복원(위상학적 성분 최대 채움)하는 학습 파라미터 0개의 비지도 이상 탐지 프레임워크입니다.**

```text
[준비 단계 (Support 통계 추출)]
정상 16장 ───> 고정 DINOv2 ───> 4개 해상도 × 4개 무작위 희소 Bank 구축
                                     │
                                     ├──> Leave-Source-Out q95 통계 산출 (꼬리 정규화용)
                                     └──> Support Leave-Source-Out q99 통계 산출 (RSG 게이팅 임계값용)

[검사 단계 (Query 추론 & 온라인 보정)]
검사 이미지 ───> 고정 DINOv2 ───> 4개 해상도에서 최근접 정상 거리 계산
                                     │
                                     ├──① 꼬리 정규화 (Tailscale): 거리 / q95_LOO
                                     ├──② Base 지도 구축: Layer 11, 23 산술 평균
                                     ├──③ 잔여 스파이크 게이팅 (RSG3): 
                                     │     Layer 5 신호 중 Support q99 임계를 넘는 잔여분(Spike)만 선택 융합
                                     └──④ 위상학적 결함 온전성 복원 (CQ):
                                           상위 1% 8-연결 성분 내부로 피크 신뢰도를 전파하여 물리적 형태 복원
                                     │
                                     ▼
                              최종 픽셀 이상 지도
```

- **학습 파라미터 0개**: Backbone 고정, LoRA 없음, MLP/분류기 없음.
- **온라인 완결성**: 모든 파이프라인이 단일 추론 루프(`reference_matching.py`) 내에 내장되어 있어 오프라인 재채점 없이 완전한 종단간 예측이 수행됩니다.

## 3. 핵심 구성 요소 상세

### 3-1. 다중 스케일 참조 매칭 (Multi-scale Reference Matching)

- 정상 support 이미지 16장을 고정 DINOv2 ViT-L/14에 통과시켜 **448, 672, 896, 1120**의 4가지 해상도에서 패치 특징을 추출
- 해상도가 커질수록 원본 이미지 픽셀 대비 패치의 수용 영역(receptive field)이 작아져 초미세 결함(`can`, `fabric`)의 희석을 방지

### 3-2. Bagged 희소 메모리 뱅크 (Bagged Sparse Memory Bank)

- 서포트 이미지당 전체 토큰을 모두 저장하는 대신, **무작위 256개 토큰**을 서브샘플링하여 희소 뱅크를 구성
- 서로 다른 무작위 시드로 생성된 **4개의 뱅크**를 병렬로 운용하고 점수를 평균(Bagging)함으로써, 극단적인 이상 토큰이 정상에 흡수되는 현상을 막고 서브샘플링 분산을 통제

### 3-3. 상위 꼬리 정규화 (Tailscale Normalization)

- [AUPRO@0.05](mailto:AUPRO@0.05) 및 [pAUROC@0.05](mailto:pAUROC@0.05)는 False Positive Rate가 상위 5% 이내인 **극단 꼬리(Extreme Tail)** 영역만을 적분
- 기존 MAD 기반 정규화($d / (1.4826 \cdot \text{MAD})$)는 분포의 중심에 초점을 맞추어, 꼬리가 두꺼운 레이어/스케일이 5% 오탐 예산을 과도하게 독점하는 문제를 낳았습니다.
- **Tailscale**은 서포트 이미지의 Leave-Source-Out $q_{95}$를 분모로 사용하여 각 성분의 꼬리 소비율을 1:1로 정확히 정합합니다:
  $$
  S_{l, s}(x) = \frac{d_{l, s}(x)}{q_{95}^{\text{LSO}}(l, s)}
  $$
- 선형 변환이므로 비선형 랭크 변환과 달리 원거리 이상 신호의 절대적 강도(Magnitude)를 100% 보존합니다.

### 3-4. 잔여 스파이크 게이팅 (Residual Spike Gating with Adaptive Tail Thresholding, RSG3)

- **배경**: 중간 레이어($L_{11}, L_{23}$)로 구성된 Base Map은 전반적인 의미론적 이상을 안정적으로 잡아내지만, `can`과 같은 고주파 표면 스크래치는 얕은 레이어($L_5$)에서만 검출됩니다. 그러나 $L_5$를 단순 산술 합산(TB3)하면 정상 텍스처 노이즈가 급증하여 `fabric` 점수가 급락(59.2% $\to$ 51.7%)합니다.
- **메커니즘**: Base Map($S_{\text{base}}$)과 $L_5$ 지도($S_5$) 간의 **잔여분(Residual)**을 정의하고, 정상 서포트의 꼬리 통계로부터 유도된 임계값 $\tau_5$를 초과하는 "극단적 스파이크"만을 게이트로 통과시킵니다:
  $$
  R_5(x) = \max(0, S_5(x) - S_{\text{base}}(x))
  $$
  $$
  G_5(x) = \begin{cases} R_5(x) & \text{if } R_5(x) > \tau_5 \\ 0 & \text{otherwise} \end{cases}
  $$
  $$
  S_{\text{final}}(x) = S_{\text{base}}(x) + G_5(x)
  $$
- **Support-Quantile 적응형 임계값 산출 (**$q=0.990$**)**:
임계값 $\tau_5$를 고정하지 않고, 서포트 세트의 Leave-Source-Out $q_{99}$ 분위수를 기반으로 클래스 특성에 맞게 자동 적응시킵니다:
  $$
  \tau_5 = \frac{\operatorname{Quantile}(S_{5, \text{support}}, 0.990)}{u_{95}}
  $$
  - **불투명 텍스처** (`fabric`, `rice`, `walnuts`): $\tau_5 \approx 1.13 \sim 1.18$로 낮아져 미세 결함 통과 극대화.
  - **금속/반사체** (`can`, `sheet_metal`, `vial`): $\tau_5 \approx 1.19 \sim 1.36$로 반사 노이즈 차단 및 스크래치 융합 (`can` +2.91 pp 수직 상승).
  - **반투명체** (`fruit_jelly`): 정상 굴절광 노이즈(99th 백분위수 1.55)를 정확히 상회하는 $\tau_5 \approx 1.74$가 자동 형성되어 노이즈 100% 차단 (`fruit_jelly` +2.04 pp 상승).

### 3-5. 결함 형태학적 온전성 복원 (Topological Completeness Restoration via CQ)

- **배경 (패치 표현의 공간적 불균일성)**: DINOv2 등 사전학습된 ViT 패치 임베딩은 결함 경계부의 고대비 에지에는 강하게 반응하지만, 동일한 결함 덩어리 내부의 평탄 영역이나 주변부에서는 반응 강도가 급격히 감쇠하여 결함이 중심부만 듬성듬성 감지되는 **공간적 파편화(Spatial Fragmentation)**를 겪습니다.
- **물리적 원리 (위상학적 신뢰도 전파)**: 산업 결함(스크래치, 균열, 오염 등)은 분절된 노이즈가 아닌 **공간적으로 연속된 물리적 개체(Topologically Connected Entity)**입니다. 따라서 한 연결 영역 내에서 극단적인 이상 피크 신호(극단 상위 분위수)가 확인되었다면, 그와 물리적으로 맞닿아 있는 성분 내부 역시 동일 결함에 해당할 확률이 지배적입니다.
- **CQ 알고리즘**:
  1. 검사 이미지의 예측 점수 지도에서 이미지 자체의 상위 분위수(예: $q_{\text{cq}}=0.99$)로 고신뢰도 결함 후보 마스크를 생성합니다.
  2. 8-연결(8-connected) 성분을 라벨링하여 개별 결함 개체들을 분리합니다.
  3. 각 연결 성분 내부의 모든 픽셀 점수를 **해당 성분 내의 최대 피크 점수($\max S(x)$)**로 채워 결함 덩어리의 구조적 온전성을 완성합니다.
- **특징 및 지표 독립성**:
  - 임계값과 채움 모두 테스트 이미지 자체의 내부 분포로부터 결정되는 완전한 비지도 기법입니다.
  - 이미 상위 1%로 확신된 고신뢰 영역 내부만 평준화하므로, 정상 배경 영역의 순위를 왜곡하지 않아 가드레일 지표인 [**pAUROC@0.05](mailto:pAUROC@0.05)를 완벽히 보존**합니다.
  - 동시에 결함 덩어리의 온전한 분할을 회복하여 **F1-oracle 점수(34.2% $\to$ 35.87%)**와 세그멘테이션 정밀도를 대폭 끌어올립니다.

## 5. 주요 기여 및 독창성 (Key Contributions &amp; Novelty for CVPR)

### Contribution 1: Low-FPR 결함 평가를 위한 "상위 꼬리 정규화 (Tailscale Normalization)" 규명

- 대부분의 이상 탐지 연구가 전체 ROC-AUC에 집중하여 분포의 중심(Center/Spread) 기반 정규화(Z-score, MAD)를 사용해 왔음을 비판하고, 산업 결함 감지 표준인 Low-FPR ([AUPRO@0.05](mailto:AUPRO@0.05))에서는 **특징 성분 간의 꼬리 두께(Tail Heaviness) 불균형이 특정 레이어의 오탐 독식으로 이어진다**는 새로운 통찰을 제시했습니다.
- 비지도 Leave-Source-Out $q_{95}$ 스케일링을 통해 이상 신호의 절대 크기 순위를 왜곡하지 않고 완벽하게 오탐 소비율을 일치시키는 이론적/실증적 해법을 입증했습니다.

### Contribution 2: 다중 계층 융합의 딜레마를 해결한 "적응형 잔여 스파이크 게이팅 (RSG with Support-Quantile Thresholding)"

- 고주파 미세 결함을 잡기 위한 얕은 레이어(Layer 5)와 의미론적 구조를 잡는 중간 레이어(Layer 11, 23)를 결합할 때 발생하는 **"미세 결함 검출 vs 정상 텍스처 노이즈 폭증" 간의 근본적 트레이드오프**를 수학적으로 정식화했습니다.
- Base Map 대비 잔여분(Residual)에만 비선형 게이트를 적용하고, 임계값을 **서포트 이미지의 **$q=0.990$** 분위수로부터 비지도 방식으로 도출**하여, 투명 젤리의 굴절광은 차단하고 금속 표면의 미세 스크래치는 통과시키는 완전 자동 적응형 다중 레이어 융합을 실현했습니다.

### Contribution 3: 패치 표현의 공간적 파편화를 극복하는 "위상학적 결함 온전성 복원 (Topological Defect Completeness Restoration via CQ)"

- 사전학습된 Vision Transformer가 결함 중심부의 고대비 에지만 감지하고 동일 결함 덩어리 내부/주변부에서 응답이 감쇠하여 발생하는 **공간적 파편화(Spatial Fragmentation)** 문제를 체계적으로 규명했습니다.
- 물리적 결함이 공간적으로 연속된 하나의 개체(Connected Entity)라는 도메인 특성에 기반하여, 극단적 이상 피크 신뢰도를 위상학적으로 연결된 결함 영역 내부로 전파하는 완전 비지도 알고리즘(CQ)을 제안했습니다.
- 이는 특정 평가 지표의 휴리스틱 트릭이 아닌 물리적 형태 복원 기법으로서, 정상 배경의 순위를 훼손하지 않으면서(pAUROC 보존) 결함 마스크의 온전한 분할을 회복하여 세그멘테이션 정밀도(F1-score)와 검출 완성도를 획기적으로 향상시켰습니다.

### Contribution 4: 제로 파라미터(Zero-Parameter), 제로 학습(Zero-Training) 비지도 프레임워크

- 별도의 MLP 보정기(CRR 등)나 파라미터 어댑터(LoRA), 대규모 추가 학습 없이 **사전학습된 범용 DINOv2 백본과 16장의 서포트 이미지 통계만으로** 동작합니다.
- 복잡한 튜닝이나 도메인별 하이퍼파라미터 변경 없이 8개 클래스 전체에 대해 단일 고정 파이프라인으로 일관되게 최첨단 성능을 달성하여 실무 적용성과 재현성을 극대화했습니다.
